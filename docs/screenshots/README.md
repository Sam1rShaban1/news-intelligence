# Screenshots

Add UI screenshots here for the README "Screenshots" section.

With the stack running locally (`docker compose up`), capture each view in the browser
(`http://localhost:8501`) and save as:

- `overview.png` — Overview dashboard (KPI cards, sentiment-over-time, language mix, trending).
- `explore.png` — Explore search with filters applied.
- `entities.png` — Entities directory with the entity inspector open.
- `graph.png` — Knowledge-graph canvas with a node selected.
- `stories.png` — Stories / event clusters.

Recommended size: 1280×800 (or wider), PNG, trimmed to the app frame.
